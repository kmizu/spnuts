# SPnuts 0.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish runnable SPnuts 0.1.0 JVM and Linux Native distributions, with documentation and byte-identical downloads deployed on GitHub Pages.

**Architecture:** A package script emits release archives and checksums. A second script renders a static Pages payload from those exact artifacts. A tag/manual GitHub Actions workflow validates, releases, and deploys the payload.

**Tech Stack:** Scala 3.3.1, sbt, Scala Native, Bash, GitHub Actions, GitHub Pages.

## Global Constraints

- Version is `0.1.0`; release tags are `v<version>`.
- JVM bundle is self-contained and requires Java 17+.
- Native bundle is Linux x86_64 only.
- Pages includes the exact release archives and `SHA256SUMS`.
- The release makes no language syntax or semantic changes.
