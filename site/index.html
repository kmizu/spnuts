What's new in SPnuts {{VERSION}}

Mandatory gradual typing checks each complete chunk before it runs. Unannotated bindings get fixed inferred types, while Any keeps Java, host, and eval boundaries dynamic.

var count = 1
count = count + 1
count = "two"  // Type error: rejected before the chunk runs

Type errors include expected and actual types, source position, and a caret. A rejected chunk publishes neither side effects nor inferred type state.

Quick start

tar -xzf spnuts-{{VERSION}}-jvm.tar.gz
./spnuts-{{VERSION}}-jvm/bin/spnuts

# Or run a script
printf 'println("hello, SPnuts!")\n' > hello.pnuts
./spnuts-{{VERSION}}-jvm/bin/spnuts hello.pnuts

The Linux Native archive has the same bin/spnuts interface. Java interoperation is available in the JVM distribution only.

Interactive use

pnuts> function fib(n) {
.....   if (n <= 1) n
.....   else fib(n - 1) + fib(n - 2)
..... }
pnuts> fib(10)
55

The REPL supports multi-line input, :load PATH to evaluate a file in the current session, and :bindings to inspect values defined in that session.

Why this release

Pnuts was created at Sun Microsystems by Toyokazu Tomatsu. After receiving permission to continue the project, SPnuts carries that work forward as a Scala implementation. Version 0.2.0 adds mandatory gradual typing.

Source, issue tracking, and build instructions live at github.com/kmizu/spnuts. SPnuts is distributed under the Sun Public License 1.0 used by Pnuts.
